# Generated State

This directory is intentionally empty in the public template.

Runtime files created by `/scan`, `/filter`, `/generate`, and `/tracker` are ignored:

- `filter-progress.json`
- `generation-progress.json`
- `output-links-state.json`
- `applied-jobs.json`
- `filter-results.md`
- `application-tracker.md`
- `scan-history.json`
- `filter-temp-*.json`
- `filter-results-temp-*.md`
